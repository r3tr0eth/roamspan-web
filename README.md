# roamspan.app

Marketing site for **Roamspan** (iOS Schengen 90/180).

**English is the primary language** (`/` and `/privacy/`). Spanish is secondary at `/es/` and `/es/privacy/`. There is no Accept-Language redirect: the homepage is always English.

Static HTML. Deploy on Vercel. Point `roamspan.app` at the project.
